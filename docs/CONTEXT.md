# 算子优化探索

探索过程及其知识来源的领域用语。

**探索图**：持久记录优化方案、知识、经验及其派生、参考和证据关系的图。独立于执行它的 Agent session。
_Avoid_: 搜索树、单父工作树

**方案节点（Node）**：一个具体优化假设及其代码和实验过程，可有多个来源或独立起点。

**Stage / Attempt**：方案内部的工作阶段及该阶段的一次实际执行；Attempt 保留执行者、准确输入输出与结果。

**派生／融合**：从一个或多个已有方案构成新方案的关系；所有此类关系必须无环。

**参考**：制定方案时采用的知识、经验或实验依据，不等同于收益的实验证明。

**支持／反驳**：明确实验对知识或经验主张的支持或反例；不自动证明普遍因果。

**Agent session**：持续执行任务的可替换智能体身份，不拥有探索图或固定节点。
